1. Identity Domain

    Everything related to authentication and the user's application identity.

    Features

        Sign in
        Sign out
        Invitation acceptance
        Account creation
        Account profile
        Edit profile
        Avatar
        Manager vs End User permissions
        User status: pending / active / disabled


2. Restaurant Domain

    Defines the restaurant's operational structure.

    Features

        Areas
        Create area
        Edit area
        Activate/deactivate area
        Roles
        Create role
        Edit role
        Activate/deactivate role
        Area → Role relationships
        Assign employees to areas/roles


3. User / Employee Domain

    Manages the restaurant's people.

    Features

        Employee list
        Create employee
        Employee profile
        Edit employee
        Disable employee
        Employee invitation
        Invitation status
        Assign areas
        Assign roles
        Employee availability
        Hourly pay rate
        Employee schedule history


4. Requirements Domain

    Defines how much staffing the restaurant needs.

    Features

        Create staffing requirement
        Edit requirement
        Delete/deactivate requirement
        Area requirement
        Role requirement
        Day of week
        Start time
        End time
        Required employee count
        Copy requirements
        Recurring/default requirements
        Requirement validation


5. Scheduling Domain

    This is the core domain of the application.

    Features

        Create weekly schedule
        View week
        View day
        View area
        Create shift
        Edit shift
        Delete shift
        Assign employee
        Assign area
        Assign role
        Set shift start/end
        Copy shifts
        Duplicate previous schedule
        Draft schedule
        Publish schedule
        Update published schedule
        Schedule status


6. Schedule Validation Domain

    This is technically part of scheduling, but I'd treat it as its own domain/service layer because it will become important.

    Features

        Coverage gaps
        Role mismatch
        Availability conflicts
        Employee overlap
        Excess hours
        Missing assignments
        Invalid shifts
        Staffing status
        Schedule health


7. Communication Domain

    Manager ↔ Employee communication.

    Features

        Conversations
        Manager ↔ employee conversation
        Send message
        Receive message
        Read/unread state
        Conversation list
        Message history
        Basic notifications


8. Notification Domain

    Notifications generated by the other domains.

    Features

        Schedule published
        Schedule changed
        Shift changed
        New message
        Shift canceled
        Invitation received
        Unread notifications


9. Account Domain

    This is separate from identity.

    Features

        View account
        Edit account
        Change personal information
        Avatar
        Account preferences
